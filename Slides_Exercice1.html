Le contexte

Tu es développeur WordPress.

    Un client fictif te mandate pour créer son site.

    Tu choisis librement le thème — mais il doit avoir une vraie identité.

Étape 0 — Avant de coder

Choisis ton univers

Avant d'ouvrir VS Code, décide de 3 choses :
1. Le sujet du site  ·  2. Le nom du site  ·  3. La couleur principale

Idées de sujets
Contenu
Blog de recettes · Jeux vidéo · Voyages · Cinéma · Sport · Musique · Mode
Exemple de nom
Identité
"PixelBlog" · "Taste & Go" · "WanderLog" · "GameZone" · "CineClub"
Couleur principale
CSS Variable
Définis --color-primary dans ton style.css et utilise-la partout.
Étape 1 · 25 min

Mise en place

Créer un nouveau site dans Local → tonnom.local
Créer un dossier thème dans wp-content/themes/ avec le nom de ton site
Créer style.css avec l'en-tête WordPress (Theme Name, Author, Version, Description)
Créer functions.php avec add_theme_support pour les thumbnails et le title-tag
Ajouter ta couleur principale comme variable CSS dans style.css : :root { --color-primary: #... }
Activer le thème dans Admin → Apparence → Thèmes
Étape 2 · 20 min

Header & Footer

Créer header.php avec la structure HTML complète
Afficher le nom du site dans le header via bloginfo('name')
Ajouter un logo ou icône dans img/
Créer footer.php avec wp_footer() et un texte de copyright

Challenge CSS :
Utilise ta variable --color-primary pour la couleur de fond du header. Ton site doit avoir une vraie identité visuelle, même simple.

Étape 3 · 20 min

Contenu fictif

Créer 3 catégories cohérentes avec ton sujet
Créer 3 pages : Accueil, Blog, Contact
Écrire un vrai texte de présentation sur la page Accueil (pas lorem ipsum)
Configurer Réglages → Lecture → page statique
Générer 15 articles avec FakerPress dans tes catégories

⚠️ Le texte de la page Accueil doit présenter le site comme si c'était un vrai client. C'est ce qui s'affichera sur front-page.php.

Étape 4 · 45 min

Les templates

1
front-page.php accueil
Afficher le titre + contenu de la page Accueil. Ajoute un élément visuel fort (grand titre, phrase d'accroche).
2
home.php liste blog
Afficher titre, image, extrait et lien pour chaque article. Utilise the_post_thumbnail().
3
archive.php catégorie
Même structure que home.php. Ajoute le nom de la catégorie en titre avec the_archive_title().
4
single.php article
Article complet : titre, image, contenu, date, auteur, catégorie + lien "Retour au blog".
Challenge

Va plus loin que les élèves

  • 🎨
    CSS cohérent — tout le site utilise ta variable --color-primary. Header, boutons, liens, dividers.
  • 🏠
    Page d'accueil enrichie — affiche les 3 derniers articles en bas de front-page.php avec une WP_Query.
  • 🔗
    Navigation cohérente — un lien "Blog" dans le header qui pointe vers la page des articles.
  • 📱
    Responsive minimum — la liste d'articles passe en colonne unique sur petit écran avec une media query.
Critères de réussite

Ce qu'on va vérifier

  • ✅
    Le thème est activé et visible dans l'admin
  • ✅
    La page d'accueil affiche le contenu de la page "Accueil"
  • ✅
    La page Blog liste les articles avec image, titre, extrait, lien
  • ✅
    "Lire la suite" ouvre l'article complet
  • ✅
    La page d'une catégorie fonctionne
  • ⭐
    Le site a une identité visuelle reconnaissable
  • ⭐
    La variable CSS --color-primary est utilisée
  • ⭐
    Le footer affiche l'année et le nom du site dynamiquement
  • ⭐
    L'article a un lien "Retour au blog"
Rendu

Comment partager ton travail

Option A — En ligne
Live Link

Option B — Fichier

Compresser le dossier du thème en .zip → envoyer par email ou Teams. Le prof l'installe chez lui.

💡 Avant d'envoyer, vérifie que toutes les pages fonctionnent en cliquant dessus dans Chrome.
